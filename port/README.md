# Cloud Port Installer

Порт PortMaster, который скачивает архивы портов (.zip, .7z, .rar) из облака и раскладывает их
по папкам вашей прошивки (muOS, ROCKNIX, KNULLI).

## Как пользоваться

1. Запустите «Cloud Port Installer» из раздела Ports.
2. **Облака → «+ Добавить облако»**: название (необязательно), публичная ссылка на файл или папку
   (Яндекс.Диск, Google Drive, Mail.ru, либо прямая ссылка на архив), тип — обычно «Авто».
   Облаков можно сохранить сколько угодно; список можно также править в `data/settings.json`.
3. Откройте облако — на весь экран появится список архивов (подпапки Яндекс.Диска обходятся сами).
   **X** — отметить архив, **Y** — отметить все, **A** — установить отмеченные (или выделенный).
4. Новый порт появится в списке Ports; список игр, возможно, придётся обновить или перезапустить интерфейс.

## Установленные порты

Пункт меню «Установленные порты» показывает всё, что лежит в папках портов прошивки (на muOS —
обе SD-карты): имя, размер, дату и что именно есть — **«sh + папка»**, **«только sh»** (папки нет) или
**«только папка»** (нет .sh). **A** — подробности и пути, **X** — удалить (с подтверждением; удаляются
и .sh, и папка), **Y** — сортировка (имя / размер / дата). Само приложение и PortMaster не удаляются.

## Управление

| Кнопка | Действие |
|---|---|
| D-pad | выбор |
| A | открыть / подтвердить |
| B | назад / отмена |
| X | отметить архив · удалить облако или порт |
| Y | отметить все · изменить облако · сортировка |
| Start | на клавиатуре: готово |

Если A и B работают наоборот: Настройки → «Кнопки A/B» → «Поменять A и B».

## Файлы

- `data/settings.json` — настройки
- `data/paths.user.json` — свои пути для других прошивок/устройств (схема как в `config/paths.json`)
- `data/logs/installer.log` — журнал
- `log.txt` — вывод последнего запуска (присылайте его при проблемах)
