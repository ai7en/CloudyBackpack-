# Cloud Port Installer

Порт PortMaster, который скачивает архивы портов (.zip, .7z, .rar) из облака и раскладывает их
по папкам вашей прошивки (muOS, ROCKNIX, KNULLI).

## Как пользоваться

1. Запустите «Cloud Port Installer» из раздела Ports.
2. Настройки → «Ссылка на облако»: введите публичную ссылку на файл или папку
   (Яндекс.Диск, Google Drive, Mail.ru, либо прямую ссылку на архив).
   Ссылку проще один раз вписать в `data/settings.json` с компьютера.
3. «Установить порт из облака». Новый порт появится в списке Ports; список игр, возможно,
   придётся обновить или перезапустить интерфейс.

## Управление

| Кнопка | Действие |
|---|---|
| D-pad | выбор |
| A | подтвердить |
| B | назад / отмена |
| X, Y, Start | на экранной клавиатуре: удалить, регистр, готово |

Если A и B работают наоборот: Настройки → «Кнопки A/B» → «Поменять A и B».

## Файлы

- `data/settings.json` — настройки
- `data/paths.user.json` — свои пути для других прошивок/устройств (схема как в `config/paths.json`)
- `data/logs/installer.log` — журнал
- `log.txt` — вывод последнего запуска (присылайте его при проблемах)

## Лицензии
